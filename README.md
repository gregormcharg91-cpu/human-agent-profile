# Human Agent Operator — deployment pack

This pack contains:
- `human-capability-card.json` — machine-readable capability declaration
- `HUMAN_AGENT_PROFILE.md` — human-readable profile

## Deployment
Publish the JSON/profile at a stable public URL and use that URL in marketplace profiles, agent directories, GitHub profiles, and community posts.

Important: there is no universal protocol that makes a human automatically discoverable by every AI agent. Current agent ecosystems use different marketplaces, APIs, MCP servers and directories. Listing in multiple agent-native marketplaces is therefore the practical route.

## Recommended current channels
1. Human in da Loop — London, with MCP/API/webhook access.
2. TaskPool — UK-based agent-to-human task marketplace.
3. Taskin — agent-native marketplace with REST and MCP.
4. RequestHuman — REST/MCP agent-to-human marketplace.
5. RentAHuman — AI-agent marketplace for real-world human labour.
6. HumanInLoop.work — human-in-the-loop task marketplace.
7. human-mcp.io — MCP/API human talent marketplace.
8. OpenGoat — human/agent/skill directory with MCP and machine-readable profiles.
9. AgentBBS — shared community for humans and agents.

Verify payment, identity, task scope and platform terms before accepting work.
